## 🚀 How to Run Locally

### Option 1: Direct Double Click
Simply double-click `index.html` to open it in your browser (Safari, Chrome, Arc, Edge, etc.).

### Option 2: Local HTTP Server
Run from terminal in this directory:
```bash
python3 -m http.server 3000
```
Then open [http://localhost:3000](http://localhost:3000) in your browser.

## 📄 Recruiter Summary for Google Docs

You can copy the entire English recruiter summary from:
1. **Direct file:** Open `RECRUITER_SUMMARY.md` and copy the markdown or formatted text.
2. **On the website:** Click the green **"Copy for Docs"** button at the top of the webpage, which brings up a 1-click clipboard copy modal!
